# leonardotireck.com

Source code for [leonardotireck.com](https://leonardotireck.com), Leonardo Tireck's personal website and software development portfolio.

The site is a statically exported Next.js application deployed to Cloudflare Pages.

## Stack

- Next.js 16 with the App Router
- React 19
- TypeScript in strict mode
- ESLint with the Next.js Core Web Vitals and TypeScript configurations
- pnpm
- Cloudflare Pages
